# Class 9 Mathematics Lab Portal
> **Andhrapradesh Mathematics Forum (APMF)**  
> *The Largest Math Forum in India*

An interactive, premium-grade web portal hosting visual mathematics simulations mapped directly to the **NCERT Class 9 Mathematics** syllabus. Students and teachers can drag, edit, and interact with visual models to master core math concepts.

---

## 📌 Pinned Note
> **Curriculum Scope:** This website is useful for all the Students who follows NCERT curriculum across INDIA.

---

## 🚀 Key Features

- **12 Interactive Chapters:** Covered sequentially from Number Systems to Statistics.
- **Visual Learning:** Dynamic graphs, vectors, grids, and 3D shapes.
- **Mastery Tracker:** Checkbox tracking for student progress saved locally to the browser's `LocalStorage`.
- **Search & Filtering:** Search by topic, chapter, or keyword, with quick filter tabs for category divisions (Algebra, Geometry, Mensuration, Statistics).
- **Responsive Layout:** Optimized for mobile phones, tablets, and desktops, including in-app full-screen simulation controls.
- **Zero-Dependency Serving:** Natively works out of the box on standard web servers or static hosts like GitHub Pages.

## 🛠️ How to Run Locally

You can launch this website locally in two ways:

### Option A: Open Directly
Simply double-click the `index.html` file in your file explorer. It will open in your default browser.

### Option B: Local HTTP Server (Recommended)
Running it through a local HTTP server prevents browser CORS security flags on iframe overlays.

1. Open PowerShell in this folder.
2. Run the custom zero-dependency PowerShell server script:
   ```powershell
   powershell -ExecutionPolicy Bypass -File "serve.ps1"
   ```
3. Open your browser and navigate to: **[http://localhost:8080/](http://localhost:8080/)**
